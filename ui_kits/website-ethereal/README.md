# Website UI Kit — Ethereal Direction

A psychedelic / funk / blues / soul re-imagining of the Vibemind website. Same content & navigation as the standard kit (`/ui_kits/website/`), but the visual language leans into the **music's spiritual ancestry**: Hendrix, Pink Floyd, The Doors, Mazzy Star, Stevie Wonder, Lauryn Hill.

## What's different from the base kit

- **Background.** A slow-drifting cosmic gradient (lava-lamp psychedelia) sits behind every page. Pinks, purples, blues, oranges — bleeding through blur. Subtle vinyl noise overlay across content.
- **Typography.** Big display headlines mix the chunky Bowlby slabs with **italic Georgia serif** for one or two key words ("go", "in the wild", "One signal"). Pulls in the soul-album-cover feel.
- **Hero.** Conic-rainbow halo orbits behind the headline. Headline uses a peach→magenta→purple→blue gradient text fill — channeling sunset-into-blacklight.
- **Music page.** Tap **Psychedelic / Funk & Soul / Blues** to dim the rest of the cover-band list — the user can *steer the spirit* of the show.
- **Member cards.** Glass cards with member-color halation. B&W portrait fades to color on hover. Each member now lists which artists they "channel" (curatorial easter egg).
- **Gig rows.** Glass capsules with neon dot + outline. Vibetrip rows glow pink, Vibemind rows glow yellow — the lineup is *colored*, not just labeled.
- **Tip Jar.** Slowly-rotating conic rainbow blur behind the headline.

## Use this when

- The brand feels too clean and you want to lean into the music's mystique.
- Promoting a show with a heavier psych/funk slant.
- Comparing against the base kit to find the right balance.

## Files
- `index.html` — page shell + the cosmic background
- `components.jsx` — all sections, ethereal-styled
